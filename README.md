# Word Counter

Count words, characters, sentences and reading time as you type, with live limits for posts, messages and search snippets.

**Use it online (free, no signup):** https://musman550.github.io/word-counter/

## Why use it
- Runs completely in your browser: what you type is never uploaded or stored.
- Free, open source (MIT) and without limits or accounts.
- Works on phones and desktops.

## Run it yourself
Download `index.html` from this repository and open it in a browser. Nothing else is needed.
